# 🚀 AI Job Portal - Frontend

A modern AI-powered Job Portal built using React.js that helps job seekers search jobs, apply for positions, manage profiles, and receive AI-powered career guidance.

## 🌟 Features

### User Features

* User Registration
* User Login
* Profile Management
* Browse Jobs
* Apply for Jobs
* Track Applications

### AI Features

* 🤖 AI Career Assistant
* 📄 AI Resume Analyzer
* Career Guidance
* Resume Improvement Suggestions

### Dashboard Features

* Total Jobs
* Total Applications
* Profile Completion Status
* Quick Navigation

## 🛠️ Tech Stack

* React.js
* React Router DOM
* Axios
* JavaScript
* CSS3

## 🌐 Deployment
