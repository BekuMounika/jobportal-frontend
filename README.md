# 🚀 AI Job Portal - Frontend

An AI-powered Full Stack Job Portal built using React.js that helps job seekers search jobs, apply for positions, manage applications, and leverage AI tools for career growth.

## 🌐 Live Demo

Frontend (Vercel)

https://jobportal-frontend-nfza.vercel.app

Backend API

https://jobportal-backend-r02c.onrender.com

## ✨ Features

### Authentication

* User Registration
* User Login
* Session Management

### Job Management

* Browse Jobs
* Search Jobs
* View Job Details

### Applications

* Apply for Jobs
* Track Applications
* Application History

### Profile Management

* View Profile
* Update Profile
* Profile Completion Status

### AI Features

* 🤖 AI Career Assistant
* 📄 AI Resume Analyzer
* Career Guidance
* Resume Improvement Suggestions

### Dashboard

* Total Jobs
* Total Applications
* Profile Status
* Quick Actions

## 🛠️ Tech Stack

* React.js
* React Router DOM
* Axios
* JavaScript
* CSS3
* Gemini AI API

## 📦 Deployment

* Frontend Hosted on Vercel
* Connected with Spring Boot Backend
* Cloud Ready Architecture

## 🚀 Installation

```bash
npm install
npm start
```

Application runs on:

```text
http://localhost:3000
```
